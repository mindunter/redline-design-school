# Redline Design School

A free, self-paced course for learning product design: 9 modules, 27 lessons, a practice brief and quiz in every lesson, and reference images generated with Codex.

**Live site:** https://mindunter.github.io/redline-design-school/

Progress, quiz answers and notes are saved in your own browser (localStorage), so nothing leaves your device.

Every "Go deeper" link was checked to make sure it loads the page it names.
